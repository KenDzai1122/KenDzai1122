## 🚀 Hướng dẫn sử dụng

1. **Clone về máy:**
   ```bash
   git clone https://github.com/KenDzai1122/fallinlove.git
   cd fallinlove
   ```
2. **Chạy local:**
   - Mở `index.html` bằng trình duyệt (khuyên dùng Chrome/Edge mới).
   - Đảm bảo các file ảnh, nhạc, script cùng thư mục.
3. **Tùy chỉnh:**
   - Thay đổi thông tin cá nhân, dự án, payment trong `index.html`.
   - Thay avatar, ảnh project trong thư mục `img/`.
   - Thay đổi hiệu ứng, màu sắc trong `style.css` và `script.js`.
4. **Triển khai:**
   - Có thể upload lên GitHub Pages, Vercel, Netlify, hoặc server bất kỳ.
